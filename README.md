> 现代都市爽文 · 万人迷恋爱修罗场 · 女性向 BG 文字游戏（含 R18）

你（冬淼，22 岁小魅魔）刚毕业，穷得搬进「星野花园 601」合租屋——结果发现五个舍友**全是魅魔**！

- 🌧️ **温叙** · 阴湿自卑粘人便利店店员（灰角灰尾）

- 🎸 **黎野** · 烂人真心的驻唱歌手（酒红卷发黑角黑尾）

## 玩法
- 点击文本推进剧情；**点击画面中央立绘区域**可隐藏全部界面、欣赏完整立绘与背景，再次点击复原
- 每月上 / 中 / 下旬三个回合 + 月度小结
- 每回合 ①②③ 为剧情选项，**④ 自由行动**（输入你想做的事）
- 💗 **能量值**：吃饭、被喜爱、亲密互动回能；低于 12 会触发「枯萎」结局
- 🎵 背景音乐由引擎实时合成（柔和环境乐），右上角可开关
- 💾 进度自动保存；**14 个结局**（5 长 + 9 短）可在标题页「结局图鉴」查看
- 🔞 含 R18 章节，进入前会二次确认，18 岁以下请勿游玩

## 美术
立绘 / 头像 / 场景背景均按「女性向精绘插画风」统一生成，出处为你提供的参考素材（350+ 酒馆美化、DS 文游指令合集、预设破限大合集、女性向角色卡合集等）。
